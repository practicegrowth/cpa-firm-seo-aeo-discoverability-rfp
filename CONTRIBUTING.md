# Contributing to PracticeGrowth Resources

Thank you for your interest in contributing to PracticeGrowth's open-source resources for CPA firms and accounting practices.

## How to Contribute

### Reporting Issues

If you find an error, outdated information, or have a suggestion for improvement:

1. Check existing issues to avoid duplicates
2. Open a new issue with a clear title and description
3. Include specific details: what's wrong, where, and what the correct information should be

### Suggesting Changes

We welcome pull requests for:

- Correcting factual errors or outdated information
- Improving clarity and readability
- Adding missing sections or evaluation criteria
- Updating links and references

### Pull Request Process

1. Fork the repository
2. Create a feature branch: `git checkout -b improve/rfp-section-name`
3. Make your changes with clear, specific edits
4. Commit with descriptive messages
5. Push to your fork and submit a pull request
6. Describe what you changed and why in the PR description

### Review Process

- All contributions are reviewed for accuracy, relevance, and alignment with CPA firm needs
- We may request changes or clarifications before merging
- Contributors will be credited in commit history

## Guidelines

### Content Standards

- **Professional tone** — These resources are used by CPA firm principals and decision-makers
- **Neutral and objective** — RFP templates must not favor any specific vendor
- **Actionable** — Every section should help firms make better vendor selection decisions
- **Current** — Reflect 2026 best practices in SEO, AEO, and professional services marketing

### What We Accept

- Corrections to outdated SEO practices or algorithm changes
- New evaluation criteria based on real vendor selection experience
- Additional sections that address gaps in the RFP framework
- Improved scoring rubrics with clearer differentiation criteria

### What We Don't Accept

- Vendor-specific recommendations or endorsements
- Promotional content or service pitches
- Generic marketing advice not specific to CPA/accounting firms
- Changes that reduce objectivity of the evaluation framework

## Questions?

Open an issue or contact PracticeGrowth through our website.
