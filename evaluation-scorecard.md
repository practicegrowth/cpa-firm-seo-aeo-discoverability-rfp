# Evaluation Scorecard — SEO & Discoverability Vendor Selection

> Use this scorecard to objectively compare vendor proposals. Rate each criterion 1–5 using the rubric below. Multiply by the weight to get the weighted score. The vendor with the highest total score should advance to presentations.

---

## Scoring Rubric

| Score | Rating | Definition |
|-------|--------|-----------|
| **5** | Exceptional | Exceeds all requirements; demonstrates clear category leadership; specific, measurable proof provided |
| **4** | Strong | Meets all requirements with depth; strong evidence and case studies; minor gaps only |
| **3** | Adequate | Meets basic requirements; some evidence but lacks depth or specificity |
| **2** | Weak | Partially meets requirements; significant gaps; generic or unconvincing responses |
| **1** | Insufficient | Does not meet requirements; no evidence; response missing or irrelevant |

## Tiebreaker Criteria

If scores are within 5 points of each other, consider:

1. **Presentation quality** — Did the vendor present clearly and answer questions well?
2. **Cultural fit** — Do they understand professional services norms and communication style?
3. **Responsiveness** — How quickly and thoroughly did they respond to RFP questions?
4. **Contract terms** — Are there unfavorable clauses (auto-renewal, IP ownership, termination penalties)?
